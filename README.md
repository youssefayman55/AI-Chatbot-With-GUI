# 🖥️ GUI Voice ChatBot using Tkinter, Speech Recognition & TTS

## 🧠 Overview

This project is a **desktop AI ChatBot application with a graphical user interface (GUI)** built using **Tkinter**.
It supports both **text input and voice input**, and responds using **text-to-speech (TTS)**.

The chatbot contains a large set of predefined knowledge about **AI, Machine Learning, and Data Science topics**, making it an educational assistant as well.

---

## 🚀 Features

* 🖥️ Interactive GUI using Tkinter
* 💬 Text-based chat interface
* 🎤 Voice input using microphone
* 🔊 Voice output using Text-to-Speech (pyttsx3)
* 🧠 Predefined AI/ML/Data Science knowledge base
* ⌨️ Enter key support for sending messages
* 🧵 Multithreading for smooth voice input handling

---

## 🛠️ Technologies Used

* Python 🐍
* Tkinter (GUI Development)
* SpeechRecognition (Voice Input)
* Pyttsx3 (Text-to-Speech)
* Threading (Parallel Voice Processing)

## 🎯 How It Works

* The user can type a message or use voice input
* Voice input is converted to text using SpeechRecognition
* The chatbot matches input with predefined responses
* Response is displayed in the GUI and spoken aloud
* The conversation continues in real time
